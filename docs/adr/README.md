# Architecture decision records

Each record describes one significant decision, why it was made and what it costs.
A record is proposed in a pull request, and the maintainer accepts it. See
[ADR 0001](0001-record-architecture-decisions.md).

| ADR | Decision | Status |
| --- | --- | --- |

| [0003](0003-mcp-2026-07-28.md) | MCP specification 2026-07-28 with the official Python SDK | Accepted |
| [0004](0004-evidence-gate.md) | Evidence gate and deterministic calculation | Accepted |
| [0005](0005-licensing.md) | Licensing and ownership | Accepted |
| [0006](0006-commit-identity-and-personal-data.md) | Commit identity and personal data | Accepted |

A new record takes the next number and has the sections Context, Decision,
Alternatives considered and Consequences.
