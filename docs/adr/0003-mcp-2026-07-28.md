# 0003. MCP specification 2026-07-28 with the official Python SDK

- Status: Accepted
- Date: 2026-10-13

## Context

The MCP specification released on 2026-07-28 removes protocol sessions and the
initialize handshake, and it is not backwards compatible with earlier revisions.
Features it deprecates may be removed from 2027-07-28
([changelog](https://modelcontextprotocol.io/specification/2026-07-28/changelog)).

## Decision

- Target MCP 2026-07-28 with the official `mcp` Python SDK, version 2.
- Support stdio for local clients and Streamable HTTP for remote use.
- Every tool declares an output schema and returns structured content.
- Tool names and results carry no source-specific naming, so new sources fit behind
  the same tools.

## Alternatives considered

- An earlier revision, for wider client support today. Its remaining lifetime is
  short.
- A third-party server framework. It adds a layer between the project and the
  specification.

## Consequences

- The official SDK also serves clients of earlier revisions from the same server
  ([SDK documentation](https://py.sdk.modelcontextprotocol.io/whats-new/)), so
  older clients can connect. Spec 0001 requires a test with Claude Code and one
  other client.
- Much MCP material from 2025 describes sessions and other removed features. The
  implementation follows the current specification and ignores that material.
