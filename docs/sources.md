# Sources

OpenCited answers only from sources that pass a review. A source is added when all
of these hold:

1. **Authority.** The publisher owns the information, for example a statistics
   office, a public agency or a regulator.
2. **Licence.** Reuse is allowed for this purpose, including stored snapshots and
   evaluation sets. The licence and the required attribution are recorded below.
3. **Stable access.** A documented API or download with stable identifiers, so a
   citation still resolves later.
4. **Provenance.** Each value or passage can be tied to an identifier, a date or
   version, and a retrieval time.
5. **Risk review.** A domain where a wrong answer can harm someone, such as health,
   gets a separate review before work starts. The review covers the intended use
   and whether that use would make OpenCited a regulated product, for example a
   medical device under EU rules.
