## Goal

When this plan is done:

1. The SSB client and the MCP server meet every acceptance criterion of
   [spec 0001](../specs/0001-ssb-mcp-server.md) that does not need a release.
2. The first release is ready to run: a release workflow, a dry run against TestPyPI
   and a `server.json` for the MCP Registry. Publishing is a separate, manual step.
3. M2 has draft specifications for the snapshot store and the calculation engine,
   the evidence gate, the agent and the first evaluation set, and the decision
   records they need.

## What the research changed

The facts below were checked against primary sources and the live API on
2026-10-13. They change the specification and add three decision records.

| Finding | Consequence |
| --- | --- |
| PxWebApi 2 is SSB's production API, and the page that spec 0001 cites no longer exists | [ADR 0007](../adr/0007-ssb-pxwebapi-v2.md), and a correction to spec 0001 |
| GET URLs are limited to about 2,100 characters, and a longer URL returns an HTML page | The client switches to POST above 1,800 characters |
| `/config` publishes no call limit; the guide says 30 per minute | The client sends at most 30 requests per minute and backs off on HTTP 429 |
| SSB's API guide states that the API uses CC BY 4.0 | Open question 4 of spec 0001 has a written answer |
| The MCP SDK 2.3.0 depends on `httpx2`, which no mocking library supports yet | [ADR 0008](../adr/0008-http-client.md): one HTTP stack and a replay transport of our own |
| Pydantic loses digits when it parses JSON numbers as decimals, and DuckDB divides decimals in floating point | [ADR 0009](../adr/0009-exact-decimals.md) |

Each step is one or two pull requests. The spec 0001 task numbers are in brackets.

| Step | Work | Done when |

| 7 | M2 groundwork: draft specifications 0002 to 0005 and their decision records | The drafts are ready for review |

## Open decisions

1. Before the first release, confirm that trusted publishing works for the
   repository, and create the pending publisher on PyPI.
2. Optionally, ask SSB in writing about the rate limit, since three sources give
   three different figures.
3. Before M2 is implemented, choose the model provider and the budget for the agent
   and the evaluation runs.

## Risks

| Risk | Response |
| --- | --- |
| The MCP SDK 2.x is three months old and releases often | Pin the minor version and upgrade through Dependabot |
| SSB runs PxWebApi 2.5.0 while 2.7.0 exists, so behaviour can change | Tolerate unknown fields, log the versions from `/config`, run the nightly smoke test |
| No recorded response with the confidential symbol `:` exists yet | The test for it stays marked as an expected failure until a recording exists |

## Out of scope

- Implementing the calculation engine, the evidence gate and the agent (M2).
- Table search with embeddings, the model gateway and tracing (M3).
- The demo site (M4) and other sources.
