# Specifications

Larger work starts as a specification: the goal, the behaviour that must hold, how
it is verified and what is out of scope. A specification is approved before work on
it starts, and later changes are recorded in it.

| Status | Meaning |
| --- | --- |
| Draft | Under discussion and not ready for work |
| Approved | Accepted; work on it can start |
| Implemented | Every acceptance criterion is met and verified |
| Superseded | Replaced by a newer specification, which is linked |
